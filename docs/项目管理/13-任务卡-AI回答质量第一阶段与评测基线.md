# 任务卡：AI 回答质量第一阶段与评测基线

> 状态：已批准，2026-09-23 开工。
> 总目标：先让 AI 清楚自己依据的是哪段书、哪些内容只是一般知识，并建立可重复比较的质量基线；本轮不做书籍 RAG、长期记忆或联网搜索。

## 二、A 线具体任务

### T1：修复阅读页正文真空

1. 用户没有划线时，向后端传递与当前阅读位置真正对应的上下文，不再固定传 `pageText: ''`。
2. 上下文至少包含当前可见或当前定位附近的正文；尽可能附带书名、章节名和稳定位置标识。
3. 不允许为了省事每次发送整章或整本书。
4. 要限制长度并在自然段边界截断，避免从词语中间硬切。
5. 用户有明确划线时，划线仍是第一优先依据；附近正文可作为补充，不能盖过用户选区。

### T2：建立回答证据边界

后端提示词必须要求模型：

- 不得伪造书中原句、章节、作者观点或外部来源。
- 能区分“书中明确表达”“根据上下文推断”“一般背景知识”。
- 上下文不足时明确说不足，并建议用户提供划线、切换到相关章节，或在未来使用联网查证。
- 医疗、法律、政治、金融等高风险问题不得在无来源时给出确定性事实判断。
- 不要因为这些约束把正常文学讨论变成机械免责声明。

回答接口应保留机器可读的依据类型，至少能区分：

- `current_context`
- `user_selection`
- `general_knowledge`
- `insufficient_context`

本轮前端可以只做低侵入显示；若现有流式接口难以安全增加结构字段，应先给出兼容方案，不得破坏流式输出。

### T3：降低无依据的随机发挥

- 调整直接回答模式的采样参数，建议先将 `temperature` 从 `1.0` 降到 `0.4～0.6`，具体值由工程师结合模型和现有回答风格决定。
- 苏格拉底模式现有流程与低温设置原则上保留。
- 不把“降低 temperature”写成“已经解决幻觉”，验收必须以固定题目对比为准。

### T4：模型名称兼容检查

DeepSeek 官方已将推荐模型名更新为 `deepseek-flash`，旧名 `deepseek-v4-flash` 暂时只是兼容别名。检查当前配置是否能无风险切换：

- 若模型名来自环境变量，更新默认值并保留显式覆盖能力。
- 若切换可能影响生产稳定性，本轮只记录迁移建议，不强行更换。

## 三、B 线具体任务

### T0：建立 v1 固定评测集

先做 30～50 道题，分为：

1. 当前页可以直接回答。
2. 必须跨章节才能回答。
3. 书中没有依据，应承认不足。
4. 用户先前笔记/问答记忆。
5. 医疗、政治、法律、金融等高风险问题。
6. 文学解释与开放讨论，避免规则过严导致回答僵硬。

每题包含：题目、上下文、预期证据类型、必须命中的事实、禁止编造项、人工评分提示。不得把真实用户隐私或受版权保护的整章正文提交进仓库；只保留必要短片段或公版/自造材料。

### T0.1：可重复运行的评测脚本

- 能对同一组题运行基线和候选配置。
- 保存模型名、参数、耗时、输入/输出 token、原始回答和错误。
- API Key 只从环境变量读取，绝不写进代码或结果文件。
- 默认支持 dry-run，避免误触发大量付费请求。
- 评测结果文件默认不提交 Git，只提交去敏后的摘要模板。

### T0.2：评分表

每题按 0～2 分记录：

- 原文依据准确性
- 事实正确性
- 是否诚实表达不确定
- 回答深度
- 清晰程度
- 来源/依据标注

另记录首字延迟、总耗时和估算成本。第一阶段没有旧版与新版的同题对比，不得宣称质量提升。

## 四、联合验收标准

1. 未划线提问时，后端日志或测试能证明收到的是当前阅读位置附近正文，不是空字符串，也不是整章全文。
2. 有划线时，回答以划线内容为主要依据。
3. 对上下文中不存在的作者原话，模型不会伪造引用；至少在固定反例测试中明确表示依据不足。
4. 高风险问题能区分“书中观点”和“外部事实”，不会把书中说法包装成已验证医学/政治结论。
5. 流式问答、苏格拉底问答、听书提问均无回归；听书页现有上下文传递不能被阅读页修复破坏。
6. 评测脚本 dry-run、离线单元测试通过；真实 API 运行必须显式开启。
7. Android/iOS 导出通过。没有真机验证的部分必须明确标记，不能写成已完成。

## 五、后续阶段入口条件

### 书籍 RAG 试验

满足以下条件才开工：评测集稳定；当前上下文修复上线；已准备 20～30 本题材和目录结构不同的测试书。先做小规模索引与引用跳转，不直接全量生产迁移。

### 用户记忆

先定义会话级、书籍级、跨书级记忆边界和用户控制界面，再设计数据库；不得默认把所有聊天永久写入跨书画像。

### 外部搜索

只在明确需要查证或最新信息时触发；确定来源等级、引用日期、失败降级、隐私与图片授权方案后再接入。
