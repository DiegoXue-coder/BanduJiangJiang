1. `git fetch origin`，再 `git log --oneline main..origin/main` 看有没有别人（1号/Codex侧2号/决策层）刚推送的新内容，有就先读一遍再动手。

3. 读 `docs/项目管理/04-开发进度记录.md` 最后 10～15 条（用"续XX"或日期往前翻），搞清楚现在做到哪、有没有别人正在改同一批文件。截至本文档写成时，**1号工程师正在 `android-reader-selection-font-fix` 这个分支上做阅读器沉浸式升级任务**（见 `08-任务卡-阅读器沉浸式升级.md`），你不要碰 `ReaderScreen.js` 里跟阅读器沉浸式布局/字体相关的部分，除非任务明确要你改。
4. 用**独立的 git worktree**工作，不要复用决策层或其他会话正在用的目录。建议：
   ```bash
   git worktree add "../BanduJiangJiang-2hao-cloud" -b listen-interaction-2hao-cloud origin/main
   ```

   在新目录里开工，避免跟同机器其他会话的未提交改动互相干扰。
